# 家里电脑：安装、设置、测试（按顺序做）

给家里跑模拟盘后台 + 实盘跟单的那台 Windows 电脑用。**从上往下做，每一步做完再做下一步。**遇到报错，把整个窗口截图发给 Claude。

## 时间表

| 时间 | 做什么 |
|---|---|
| 09-30 下午（节前最后一个交易日） | 可以提前做第 0–7 步：装好后在 13:00–14:55 之间跑 order-test，剩下的时间可以切「演练」看半天 |
| 现在～10-07（国庆休市） | 第 0–6 步：准备、设置、一键安装、手机、只读测试 |
| 10-08（节后第一天）开盘 | 第 7 步：切「演练」、交易时段真实下单测试 |

| 最早 10-13 | 第 9 步：条件都满足后切「实盘」 |

## 第 0 步：一次性准备

这台电脑上要有：

1. **Git**：https://git-scm.com/download/win ，一路默认安装。
2. **Python 3.12**：https://www.python.org/downloads/ ，安装时勾选「Add python.exe to PATH」。
3. **同花顺独立下单客户端**：东亚前海证券官网下载的「网上交易 / 独立下单」客户端（窗口标题是「网上股票交易系统5.0」的那个，不是普通的同花顺行情软件）。
4. **Tailscale**：https://tailscale.com/download ，装好后用一个账号登录（手机要用同一个账号）。
5. **ToDesk 或向日葵**：用来从手机远程登录这台电脑（第 1 步说明）。

微信推送和 Jev 的两个凭证 `PUSHPLUS_TOKEN`、`TYPESAFE_API_KEY` 家里电脑以前设过的话不用管；一键安装会检查（只说有没有，不显示内容）。没设的话，在命令行里 `setx PUSHPLUS_TOKEN 你的值`、`setx TYPESAFE_API_KEY 你的值`，然后**关掉命令行窗口重新打开**。

## 第 1 步：Windows 设置（程序要一直能操作客户端）

- 设置 → 系统 → 电源和睡眠：屏幕、睡眠都改成「从不」。
- 设置 → 账户 → 登录选项：「离开后需要重新登录」改成「从不」；关掉屏幕保护程序的密码。运行中锁屏的话，程序的模拟点击打不进同花顺。
- 设置 → 更新和安全 → Windows 更新 → 更改使用时段：08:00–16:00，避免交易时段自动重启。
- 远程用 **ToDesk 或向日葵**，**不要用 Windows 自带的远程桌面（RDP）**：RDP 连着的时候屏幕被挂起，同花顺收不到模拟操作。ToDesk/向日葵的设置里把「断开连接后锁定电脑」一类的选项**关掉**。
- 电脑重启后要有人登录桌面程序才会起来。要不要设开机自动登录你自己决定：方便，但别人碰到电脑就能进桌面。不设的话，每次重启后远程进去登录一下即可。

## 第 2 步：同花顺独立下单客户端设置

打开客户端、登录账号，在菜单里的「系统设置 / 交易设置」找到下面这些项（不同版本位置略有不同，找不到就截图发给 Claude）：

- **快速交易**那一页，四项全部选「否」：撤单前确认、买入确认、卖出确认、委托成功后弹提示。
- **界面不操作超时**（有的叫「自动锁定 / 超时退出」）改成 `0` 或「从不」。
- **默认买入价格、默认卖出价格、默认数量**全部清空，不留默认值。
- 窗口**不要最小化、不要拖到屏幕外**，也不要切成精简模式。标题要是「网上股票交易系统5.0」。

**每个交易日 09:05 之前要登录好这个客户端**（交易密码不交给程序，程序不会自动登录）。可以在手机上用 ToDesk/向日葵远程登录。

## 第 3 步：Tailscale（让手机连上家里电脑）

## 第 4 步：一键安装

**要在交易时段之外做**（周一至周五 09:15–15:30 以外；国庆期间随时可以）。
**例外：第一次安装、家里还没有任何后台在跑的时候**，交易时段也可以装：不要双击，在 `E:\claude\jev-quant` 打开命令行输入 `home_setup.bat --force`。装好以后（后台在跑了）就再也不要在交易时段带 `--force` 重装。先把同花顺独立下单客户端打开并登录（不登录也能装，只是最后的检查会显示「没登录」）。

**第一次**：家里还没有 `E:\claude\jev-quant` 这个目录的话，打开命令行（Win+R 输入 `cmd` 回车）：

```

仓库是私有的，会弹出浏览器让你登录 GitHub，登录后自动继续。

目录已经有了、但里面没有 `home_setup.bat`（以前的旧版本）：在命令行里执行

```
cd /d E:\claude\jev-quant
git fetch origin
git checkout master
git pull
```

然后在资源管理器里打开 `E:\claude\jev-quant`，**双击 `home_setup.bat`**。它依次做 5 件事，每件前面有一行 `==== [x/5] ... ====`：

1. 更新代码（拉最新的 master）。
2. 准备开发目录的 Python 环境。
3. 装 easytrader（备选下单层；装不上会提示，不影响后面）。
4. **装 xiadan-gateway 下单网关**：下载到 `E:\xiadan-gateway`（固定在审查过的版本），装依赖，写配置，生成网关密码（token，自动保存，不显示），读 Tailscale 地址，建开机自启，启动网关。

5. **装运行目录 `E:\jev-live`**（只跑不改），放入公司电脑迁来的数据库（已有就不覆盖），检查凭证，建开机自启，启动模拟盘后台 `daemon.py` 和实盘程序 `live.py`。

装好后开机会自动启动 3 个东西（在「启动」文件夹里）：`Jev模拟盘后台`、`Jev实盘执行`、`xiadan网关`（最小化的黑窗口，别关它）。**以后代码有更新，再双击一次 `home_setup.bat` 就是更新。**

实盘程序装好后默认是「关闭」模式：什么都不做。

## 第 5 步：手机

1. 手机打开 Tailscale（保持连接）。
2. 手机浏览器打开第 4 步记下的 `http://100.x.x.x:8766`，然后「添加到主屏幕」，以后点图标就能打开。
3. 页面每 10 秒自动刷新，显示：模式、有没有暂停（到几点、原因）、客户端最后一次读成功的时间、程序管的持仓（股数、成本、现价、盈亏%）、待卖、今天的委托、今天跳过的信号。**不显示账户资金和你自己的持仓**（那些看同花顺 App）。
4. 按钮：
   - **暂停 30 分钟 / 1 小时 / 到收盘**：当前这一笔做完就停，之后完全不碰客户端；到点自动恢复。
   - **恢复**：手动恢复。程序因为意外「自动暂停」的，只能这样恢复（先在同花顺 App 里核对清楚再点）。
   - **立即卖出**：会二次确认。按规则卖掉程序的全部持仓，卖完后暂停到收盘。当天买的卖不了（T+1），下个交易日开盘卖。
5. **模式（关闭 / 演练 / 实盘）只能在家里电脑本机切换**：在电脑浏览器打开 http://127.0.0.1:8766 ，页面下方会多出模式按钮。手机上看不到这组按钮。
6. 微信推送（PushPlus）标题以「💰 实盘」开头：成交、没成交已撤单、暂停开始/结束、自动暂停（附原因）、09:05 自检、收盘小结等。
7. 手机上装 ToDesk/向日葵，用来每天早上远程登录同花顺。

## 第 6 步：只读测试（国庆期间就能做，不会下单）

同花顺客户端登录着，在 `E:\claude\jev-quant` 打开命令行：

```
.venv\Scripts\python scripts\live_probe.py read --broker gateway --n 20
.venv\Scripts\python scripts\live_probe.py read --broker easytrader --n 20 --exe "C:\同花顺软件\同花顺\xiadan.exe"
```

第二条的 `--exe` 换成你的 `xiadan.exe` 实际路径。**运行期间不要动鼠标键盘**（程序在操作客户端）。把两次的完整输出发给 Claude：看成功率、耗时、持仓和委托解析得对不对。

输出最后有一段「当日委托原始行」（节假日可能是空的），重点看委托时间的原文格式、撤过单以后有没有多出「撤买 / 撤卖」行——节后交易日再跑一次时一起看。

手机页面能打开、能看到「模式：关闭」，也算这一步通过。

## 第 7 步：10-08 开盘当天

**09:00 前：**

1. 手机远程登录电脑，登录同花顺独立下单客户端。
2. 在**电脑**浏览器打开 http://127.0.0.1:8766 ，模式切到「**演练**」。
3. 09:05 前后微信应收到「💰 实盘 自检通过」（模式、可用资金、程序持仓）。没收到说明后台没跑，远程看一下。

**交易时段（09:30–11:30 或 13:00–14:57，离结束至少留 2 分钟）做真实下单测试**——这是上实盘前**必须**过的一关：

```
.venv\Scripts\python scripts\live_probe.py order-test --broker gateway --code 601398 --i-understand
```

- 跑之前确认 App 里**没有任何挂单**（有的话脚本会拒绝运行），也没有别的程序、你自己也没在下单（测试要「撤最后一笔」）。实盘程序处于「演练」模式不会下单，不冲突。周末、节假日跑不了（节假日券商会直接拒单）。
- 脚本会下**两笔**买单，各 100 股，价格都远低于市价、不会成交：A = 跌停价，B = 跌停价 +0.01。然后调一次「撤最后一笔」：
  - **PASS「撤最后一笔只撤了 B」**：B 撤了、A 还挂着——正确。脚本接着再撤掉 A。
  - **FAIL「cancel_last 撤了不止一笔…绝不能上实盘」**：A 也被撤了，说明「撤最后一笔」其实按「全部撤单」执行，上实盘会把你自己的挂单一起撤掉。**看到这个就不能开实盘**。
  - 其它 FAIL 也都不能上实盘。
- 它会等你在键盘上输入 `yes` 才真的下单；任何一步出错都会提示「单子可能已经报出去了，去 App 里核对并手动撤单」——那就马上去 App 里确认没有残留挂单。
- 跑完把完整输出发给 Claude。输出里还有：委托号和「合同编号」是否一致、委托时间原文、**电脑时钟和券商的偏差**（上线前在「以管理员身份运行」的命令行里执行一次 `w32tm /resync` 校时）、撤单后有没有「撤买/撤卖」行。
- easytrader 也用同样的命令跑一次（`--broker easytrader --exe "你的 xiadan.exe 路径"`），两种都过了之后由 Claude 定用哪个。

**网关的委托号**：默认拿不到委托号（打印「(空)」）。可以试着打开：编辑 `E:\xiadan-gateway\config\app_config.json`，加一段 `"order": {"capture_entrust_no": true}`（注意 JSON 逗号），关掉最小化的 xiadan-gateway 窗口，双击 `E:\xiadan-gateway\start_gateway.bat` 重新启动，再跑一次 order-test，看委托号和「合同编号」是不是**逐字相同**。一致就保留；不一致就删掉这段，把输出发给 Claude。**改这个文件时不要动 `auth` 里的 token。**

**可选（会花一点真钱）**：手动买 100 股任意一只便宜的股票，马上跑一次 `read`，看这只的「股数」列有没有包含刚买的 100 股，告诉 Claude（程序已经做了防护，这一项是为了知道客户端的口径）。

## 第 8 步：演练 3 个交易日（10-08、10-09、10-12）

模式保持「演练」。程序照常读客户端、照常算买卖，但**不下单**，演练的「持仓」按模拟成交价记在程序账上。每天看：

- 模拟账户「超跌·主」有成交时，微信收到「买入（演练）」「卖出（演练）」，手机页面「今天的委托」里出现对应记录。
- 15:02 以后收到「收盘小结」；复盘报告里有「实盘跟单（演练）」一段。
- 练一下手机上的暂停 / 恢复 / 立即卖出，看页面和推送是否符合预期。
- 有任何「自动暂停」推送，截图发给 Claude。

**注意：演练只验证「算得对不对、流程通不通」，不会调用下单和撤单。下单路径只有第 7 步的 order-test 验证得到。**

## 第 9 步：切实盘（最早 10-13）

四个条件都满足才切：

1. 第 7 步 order-test（至少网关那种）**PASS**，读取测试正常；
2. 3 天演练没有看不懂的异常；
3. 问过客户经理：程序化交易是否需要报备，按要求办好；
4. 电脑时钟校过（`w32tm /resync`）。

然后在**电脑**浏览器 http://127.0.0.1:8766 把模式切到「**实盘**」。从演练切到实盘会自动清掉演练留下的假持仓。之后每只最多 2 万、同时最多 1 只、每天最多 2 笔买入，只做 60/00 开头的主板股票。

**不要中途从「演练」切到「关闭」再切「实盘」来回折腾**；有真实持仓时程序不允许切回演练。

## 日常使用

- **每个交易日 09:05 前登录同花顺独立下单客户端**，并留意 09:05 的「自检」推送：
  - 「自检通过」→ 正常；
  - 「自检失败」→ 客户端没登录 / 网关没起来，远程看一下；
  - **一条都没收到** → 后台（daemon 或 live.py）没在跑，远程看一下。
- **要用这台电脑（本地或远程操作鼠标键盘）之前，先在手机上点暂停**；用完再点恢复或等它到点恢复。网关每次操作都会在交易窗口里真实点击、按键，你同时操作会互相打架。
- 收到「💰 实盘 自动暂停」：推送里写着原因。先在同花顺 App 里核对（有没有挂单、成交、持仓对不对），处理好了再在手机上点「恢复」。自动暂停不会自己恢复。
- 手机页上的「恢复」只会解除你点的时候看到的那个暂停；如果弹出「暂停状态刚变了」，说明刚刚又出现了一个新的暂停，看清原因再点。
- 程序只管它自己买的票。你手动买卖同一只票：多出来的算你的；你手动卖了程序的票，程序隔 1 分钟两次读到同样的数才按客户端减账，并发推送告诉你。

## 安全规则

- **网关或 easytrader 在操作同花顺期间，不要碰这台电脑的鼠标键盘**（先在手机上暂停）。
- **绝对不要运行 `E:\xiadan-gateway\scripts\` 目录下的任何脚本**：那些是网关作者的测试脚本，会真实下单（有一个一次下 22 笔）。
- 网关的 token（`XIADAN_GATEWAY_TOKEN`、`app_config.json` 里的 `auth.token`）和其它凭证，不要发给任何人、不要截图。安装脚本和探测脚本都不会显示它们。
- 同花顺窗口不最小化、不改标题、不切精简模式。
- 交易时段不要重启电脑、不要重跑 `home_setup.bat`（它会拒绝）。

E:\claude\jev-quant\.venv\Scripts\python -m uv sync
E:\claude\jev-quant\.venv\Scripts\python -m uv pip install --python .venv\Scripts\python.exe numpy
```

网关配置 `E:\xiadan-gateway\config\app_config.json` 至少要有：`"host": "127.0.0.1"`、`"port": 5000`、`"auth": {"enabled": true, "token": "<随机串>"}`、`"window_monitor": {"enabled": true}`、`"alerts": {"webhook_url": ""}`、`"trading_app_paths": ["<xiadan.exe 完整路径>"]`。随机串用 `python -c "import secrets; print(secrets.token_hex(24))"` 生成，同一个值 `setx XIADAN_GATEWAY_TOKEN <随机串>`。启动：`.venv\Scripts\python.exe main.py`，浏览器 http://127.0.0.1:5000/health 看 `logged_in`。

easytrader（备选）：`E:\claude\jev-quant\.venv\Scripts\pip install "git+https://github.com/shidenggui/easytrader@def5a8edc5ebd7d49bf92a9f39e9e30c9bf47101" pywin32`。不要用 easytrader 仓库自带的 requirements.txt（指向 http 镜像、关了证书校验）。
