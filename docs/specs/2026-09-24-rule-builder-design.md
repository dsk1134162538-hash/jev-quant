# 面板规则搭建器（自定义策略）— 设计文档

日期：2026-09-24
状态：待审阅
前置：低吸、扫首板两份设计文档（继续有效）

## 1. 目标
用户在桌面面板里用表单（下拉框 + 数值）自由搭建交易策略，不写代码；每个自定义策略自动配主账户（Jev 拦截）+ 影子账户（不拦截），与低吸、扫首板并排运行和对比。分工不变：规则负责选股与卖出，Jev 负责拦截（可按策略开关）。

## 2. 策略结构（JSON，存库）
```json
{
  "name": "尾盘弱转强",
  "capital": 30000,
  "select":  {"mode": "all", "conditions": [Cond, ...]},
  "rank":    {"field": "amount", "order": "desc"},
  "entry":   {"mode": "all", "conditions": [Cond, ...]},
  "exits":   [{"when": {"mode": "all", "conditions": [Cond, ...]}, "reason": "止损"}, ...],
  "jev":     {"notices": true, "news": true}
}
Cond = {"field": "pct", "op": ">=", "value": 5}
     | {"field": "pct", "op": "between", "value": [-2, 0]}
     | {"field": "ret_n", "param": {"n": 5}, "op": ">", "value": 10}
     | {"field": "sentiment", "op": "in", "value": ["正常", "火热"]}
     | {"field": "time", "op": "between", "value": ["14:30", "14:55"]}
```
- 选股（select）：每分钟对股票池（主板 60/00、非 ST、上市满 60 日）求值；排序后取候选。
- 买点（entry）：对排序后的候选逐只检查，满足即进入 Jev 拦截（若开启）→ 买入。
- 卖出（exits）：按列表顺序，第一个满足的触发卖出；原因写入成交。
- 仓位：全仓单票（与现有策略一致）；资金默认 3 万。
- 时间节拍：每分钟一次（自定义策略不支持 3 秒扫描；扫首板保留为内置策略）。

## 3. 积木（字段注册表）
每个字段有：键、中文名、类型（数值/布尔/枚举/时间）、单位、可用范围（选股/买点/卖出）、参数、合法取值范围。

| 类别 | 字段 | 说明 | 来源 |
|---|---|---|---|
| 价格 | `pct` 当前涨幅、`open_pct` 开盘涨幅、`high_pct` 最高涨幅、`low_pct` 最低涨幅、`drawdown` 从最高回落（点）、`sealed` 封死涨停、`broke` 今日炸过板 | 相对昨收，% | 实时行情 |
| 量能 | `amount` 成交额（亿）、`amount_rank` 成交额全市场名次、`turnover` 换手率 %、`volume_ratio` 量比 | | 实时行情（腾讯字段 38/49 已验证） |
| 市值 | `float_mcap` 流通市值（亿）、`total_mcap` 总市值（亿） | | 实时行情（字段 44/45 已验证） |
| 历史 | `ret_n` 近 N 日涨幅、`limit_up_in_n` 近 N 日是否涨停过、`boards` 连板数、`ma_pos_n` 相对 N 日均线的偏离 %（>0 即站上） | N ∈ {3,5,10,20} | 本地收盘价库 |
| 题材 | `concept_heat` 所属题材最高热度（涨超 5% 成员数）、`leader_rank` 在该题材内的龙头分名次 | | 题材表 + 实时行情 |
| 持仓（仅卖出） | `hold_days` 持有交易日数、`pnl_pct` 相对成本盈亏 % | | 账本 |
| 环境 | `time` 时间、`sentiment` 市场情绪、`overseas` 外围 | 枚举 | 引擎共享判断 |

- 运算符：`>`、`>=`、`<`、`<=`、`between`（闭区间）、`in`（枚举）、`is`（布尔）。
- **数据缺失时条件判为不满足**（选股/买点因此偏保守；卖出条件缺数据不触发，但强制止损只依赖价格，始终可用）。
- 均线 20 日需要本地收盘价 ≥ 20 天；上线前从新浪补齐一个月历史。

## 4. 保护机制
1. **保存前体检**（服务端校验，前端即时显示）：
   - 字段/运算符/取值合法、在该区域（选股/买点/卖出）可用、数值在合法范围；
   - 同一「全部满足」组内同一字段区间无交集 → 报错（例：涨幅 >5 且 <3）；
   - **必须有止损**：卖出规则中存在只依赖 `pct` 或 `pnl_pct` 且阈值 ≤ 0 的条件，否则不允许保存；
   - 没有任何基于 `time` 或 `hold_days` 的退出 → 警告（允许保存，提示可能长期持有）；
   - 选股条件为空 → 报错。
2. **试跑预览**：用当前（或最近一个交易日收盘）全市场行情评估 选股 + 排序 + 买点，列出命中的前 20 只及各字段取值，并显示命中总数；不调用 Jev、不下单。
3. **版本与生效**：每次保存生成新版本；新版本从**下一个交易日**生效，当日仍按旧版本运行；成交与决策记录策略 id 与版本号，统计可按版本区分。
4. 同时启用的自定义策略最多 5 个（控制请求量与 Jev 调用）。

## 5. 账户与数据
- 自定义策略 id 为 `c{n}`，账户 `c{n}_main`（Jev）与 `c{n}_shadow`；账户列表改为：内置 4 个 + 已启用自定义策略的账户（动态）。停用策略：不再开新仓，已有持仓按该版本卖出规则处理完为止。
- 新表：`custom_strategies(id TEXT, version INTEGER, name TEXT, spec TEXT, created TEXT, active_from TEXT, enabled INTEGER, PRIMARY KEY(id, version))`。
- `fills`、`decisions` 增加 `version` 列（内置策略为 NULL）。
- `Quote` 增加 `turnover`、`volume_ratio`、`float_mcap`、`total_mcap`。

## 6. 运行
- 盘前：加载「今天生效」的各自定义策略最新版本；为其账户初始化资金；计算历史类字段所需数据（均线、近 N 日涨幅/涨停、连板）一次性缓存。
- 每分钟：内置低吸 tick → 扫首板 on_minute → 各自定义策略 on_minute（先卖后买，逐策略异常隔离；卖出不依赖 Jev；非当日行情不用）。
- Jev 判断与公告/消息面缓存全局共享；每个策略每分钟最多检查 10 只、错误熔断 3 次（与低吸一致）。

## 7. 面板
- 新标签页「规则」：列出内置策略（只读展示参数）与自定义策略（新建 / 复制 / 编辑 / 停用 / 查看版本历史）。
- 编辑器：分区（选股 / 排序 / 买点 / 卖出 / Jev / 资金）；每个条件一行：字段下拉 → 参数（如 N）→ 运算符 → 值；可增删行、切换「全部/任一」；卖出规则可拖动或上下移动调整顺序；右侧实时体检结果；「试跑」按钮显示预览表；「保存（明日生效）」。
- 账户卡片、净值曲线、决策筛选、复盘报告按策略动态生成。
- 推送：自定义策略主账户成交同样推送（含命中的条件与 Jev 概率）。

## 8. 不在范围内
3 秒扫描的自定义策略、分仓、真实下单、盘中立即生效、跨策略组合逻辑。

## 9. 风险
- 规则越多越容易「挖到运气」：面板在策略对比处提示样本量（成交笔数），笔数 < 20 的结果标注「样本不足」。
- 自定义规则可能大量命中导致 Jev 调用增多：每策略每分钟最多检查 10 只 + 全局缓存兜底。
