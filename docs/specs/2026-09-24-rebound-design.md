# 超跌反弹策略（第三个内置策略）— 设计文档

日期：2026-09-24
状态：用户已确认需求（家里电脑会话）
前置：低吸设计文档（买入时机、卖出规则、成交模拟、费用全部沿用）

## 1. 目标
用户实盘的打法：最近几日跌幅较大的票，买入赌反弹，反弹就走。卖出规则原沿用低吸（+1% 就走、-3% 止损，盈亏比差、需约 78% 胜率），用户改为跟踪止盈（§2）。做成与低吸并排的内置策略，主账户（Jev 拦截）+ 影子账户（不拦截），回答两个问题：
1. 超跌反弹和低吸（强势回调）哪个更赚钱；
2. Jev 排雷对超跌反弹是否有用（连跌的票更可能是公告雷导致的）。

## 2. 与低吸的差异（只换选股和买入时机的判断口径）
| | 低吸 | 超跌反弹 |
|---|---|---|
| 当日涨幅区间 | 0% ~ -3% | 沿用 0% ~ -3% |
| 近 5 日涨幅 | 不限 | **-20% ≤ ret5 ≤ 0%** |
| 近两个月连板 | 不管 | **近 40 个交易日内出现过 ≥ 2 连板的排除** |
| 排序 | 5 日涨幅从高到低 | **5 日涨幅从低到高（跌得多的优先）** |
| 尾盘/盘中 | 情绪偏弱/冰点 **或外围偏弱** → 尾盘 | **只看情绪**：偏弱/冰点（或情绪未知）→ 尾盘 14:50；正常/火热 → 盘中 |
| 卖出 | decide_sell（相对昨收） | 见 §2.1 |
| 账户 | main / shadow | rebound_main / rebound_shadow，各 3 万，全仓单票 |

### 2.1 卖出（`jevq/rules/rebound_sell.py`，买入次日起，按顺序先满足先卖；2026-09-24 用户逐条确认）
1. 持有交易日数超过 2（中间漏跑）→ 隔夜超期，开盘即卖
2. 相对买入价亏到 -2% → 止损（不受主买影响）
3. 开盘 ≤ -1.5%（相对昨收）且从当天最低拉起 ≥ 0.8 个点 → 低开反抽，必须卖（不受主买影响；当天最低 ≤ 开盘，所以「开盘 -1.5% 拉到 -0.7%」也包含在内）
4. 当天最高相对买入价 ≥ +1.5% 后启动跟踪止盈：跌回成本价 → 回到成本（保底，必卖）；从最高回落 ≥ 0.8 个点 → 跟踪止盈，但最近 3 分钟外盘增量 > 内盘增量（主买多）时先留着。外盘/内盘是全天累计值，按每分钟快照取差；快照不足两个时按没有主买优势处理
5. 最多拿 2 个交易日，第 2 天 14:55 → 到期清仓；交易日历不可用时当天 14:55 清仓

- ret5 口径与低吸相同（`closes.ret5_from_db`：昨收 / 6 个交易日前收盘 - 1，不含今日盘中）。
- 连板判定：closes 表相邻两个交易日 `close_d >= round(close_{d-1} * 1.1, 2)` 记涨停，连续两天涨停即 2 连板；缺数据的日期对视为断点，不跨缺口焊接。历史不足 41 个交易日时用已有日期尽力判断，并在日志中写明覆盖天数。
- 连板排除计算失败 → 超跌反弹当日只卖不买（排除条件是安全过滤，宁可不买）。

## 3. 情绪刷新
`SENTIMENT_REFRESH_MIN` 30 → 10 分钟（低吸与超跌共用同一个情绪判断；每日情绪 Jev 调用约 8 → 24 次）。

## 4. 运行
- 盘前：计算连板排除集；构造 `ReboundStrategy`（共享 notice/news judge 与 ret5）；只卖日 / ret5 为空 / 排除集失败 → `enabled=False`（只卖）。
- 每分钟：低吸 tick（取行情 + 刷新情绪）→ 扫首板 → **超跌反弹 on_minute(fresh_quotes)** → 自定义策略。行情取数失败的分钟给空字典，不卖不买。异常隔离，回滚并记日志。
- Jev：每分钟最多检查 10 只、错误 3 次熔断、可买性预检（与低吸相同）；否决集按 strategy='rebound' 当日恢复。
- 留痕：decisions.strategy='rebound'，trace 含 candidate（pct/ret5/rank/of/price）、notices、news、market（mode/sentiment/sentiment_trace）、outcome。

## 5. 展示
报告、推送、面板按 STRATEGIES 动态分组；面板决策筛选增加「超跌反弹」，决策明细显示候选说明与当时情绪（不显示外围）；规则页内置策略列表增加只读说明。

## 6. 数据前提
连板排除需要约 41 个交易日收盘价；上线前在公司电脑用新浪补足本地收盘价到 ≥ 60 个交易日。

## 7. 变更记录

### 2026-09-30：成交量条件 + 卖出后再买门槛（用户确认，2026-10-08 首个交易日起生效）
买入（§2 选股/排序）新增两条，卖出规则（§2.1）不变。参数在 `jevq/config.py`：`REBOUND_MIN_SHRINK_DAYS`、`REBOUND_PRIORITY_SHRINK_DAYS`、`REBOUND_REBUY_DROP`。
1. **成交量**：连续缩量（含今天，不看涨跌，口径同自定义策略的「阶梯缩量」N：今天 < 昨天 < 前天 …）**至少 3 天**才入选，**≥ 4 天的排在前面**，同档内仍是 5 日跌得多的优先。今天的量按已开盘分钟折算全天量（`jevq/rules/metrics.py::shrink_days`），**09:45 前不判断（不买）**；越接近尾盘折算越准，情绪偏弱/冰点日本来只在尾盘 14:50 买，正好是最确定的时点。量能历史缺失/不全的票不入选；整批算不出来 → 当日只卖不买。`REBOUND_MIN_SHRINK_DAYS = 0` = 不看成交量。trace.candidate 增加 `shrink_days`。
2. **卖出后再买**：同一账户当天卖出过的票（不论哪条卖出规则），现价要比**最近一次卖出价低 1% 以上**（`round(卖出价 × 0.99, 2)`，含等于）才允许再买；从 fills 表查，重启不丢；只管当天，隔天不受限。主/影子账户各查各的。原因：低开反抽卖出时价格还在买入区间内，原来会在同一分钟原价买回，白付手续费还把持有天数重置。
- 影响：规则中途变更，10-08 起的演练/实盘跟单（`rebound_main`）都按新规则；10-08 之前的成交（09-24～09-30）是旧规则。
